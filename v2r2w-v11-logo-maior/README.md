# Victoria Juris — site demonstrativo

Projeto estático em HTML, CSS e JavaScript puro.

## Como testar
Abra o arquivo `index.html` no navegador.

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. Em Settings > Pages, selecione a branch principal como fonte.
4. Salve e aguarde a publicação.

## Antes de publicar
- Troque nome, telefone, e-mail e cidade.
- Substitua a imagem externa do hero por uma imagem própria/licenciada.
- Integre o formulário a um serviço real.
- Ajuste textos jurídicos à equipe responsável.
- Revise regras profissionais aplicáveis à publicidade jurídica.

## Navegação em páginas
`O Escritório` agora abre `escritorio.html` como uma página separada. As demais seções continuam na home por enquanto.
